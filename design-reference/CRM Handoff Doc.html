What's in the prototype

Workspace (Leads)
Designed

Unified Table + Kanban view of all leads with filters, hot-lead toggles, and a slide-in detail drawer that covers activity, tasks, inventory match, and cost sheet.

Site Visits
Designed

Week calendar + day timeline. Confirmed / in-progress / completed / no-show states. Click any visit to jump to that lead.

Inventory
Designed

Tower / floor / unit grid for Abhiman Niwas. Sold · available · blocked status. Hover a unit for carpet, price, rate/sqft, all-in.

Bookings
Designed

Booking list + cost sheet detail. 4-stage progress: token → agreement → registration → registered. Document checklist per booking.

Payments & Schedule
Designed

Outstanding, due, scheduled, paid milestones. DPD calculation, reminder action, receipt look-up. Quarter collections summary.

Channel Partners
Designed

Broker directory with tier (Platinum / Gold / Silver), lead & booking counts, commission earned, outstanding payout.

Dashboard
Designed

Sales funnel, today's tasks & visits, KPI tiles. Personalised greeting + day's priorities for the logged-in user.

Reports & Settings
Stub

Navigation in place; full reports library & admin/settings screens to be specified in the next pass.

What's real vs what's a placeholder

Designed & clickable

  • Visual layout, typography, colour system, iconography
  • All 7 module screens with realistic sample data
  • Lead detail drawer with 5 tabs (activity, tasks, inventory, cost sheet, files)
  • Workspace view toggle (Table ↔ Kanban) with shared filters
  • Inventory hover-tooltip for unit details
  • Booking stage progress + document checklist
  • Payment status pills + DPD calculation
  • Tweaks panel (live colour / density / view toggles)

Not yet — needs the production build

  • Login, user roles, permissions
  • Real database, save/sync, audit log
  • SMS / WhatsApp / Email gateway integration
  • Cost sheet / agreement PDF generation
  • Payment gateway + receipt issuing
  • RERA & bank-loan API hooks
  • "+ New Lead" form, sidebar router (clicks switch state but no URL)
  • Reports library & full Settings (admin, masters, tariffs)
04

Recommended next steps

Round 2 — design polish (1 week)

  • Client review of the prototype, collect feedback
  • Lock copy, micro-flows, and edge cases (cancellation, refund, re-allocation)
  • Specify Reports library & Settings screens
  • Mobile site-visit flow (sales rep on phone, offline-tolerant)

Build phase — production app (3-5 months)

  • Backend: PostgreSQL, role-based auth, audit log
  • Frontend: React + this design system as the foundation
  • Integrations: Twilio/Gupshup, payment gateway, RERA
  • iOS/Android shell for site-visit + lead capture
  • Staged rollout: Sales team first, then Finance, then Admin

How to use the prototype

Open Real Estate CRM (standalone).html in any modern browser (double-click the file). No internet connection needed; all assets are inlined. Toggle the Tweaks control in the header to switch table/kanban density, colour temperature, and view-defaults. The data shown is illustrative — real numbers will be wired in during the production build.
